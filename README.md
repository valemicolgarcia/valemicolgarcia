## Mis Proyectos Destacados

Aquí están los proyectos que más me representan, desde agentes GenAI productivos hasta investigación aplicada en salud:

- **🍎 Nutrition Label Agent**  

  Agente agéntico que analiza etiquetas nutricionales con visión multimodal. Usa LangChain, LangGraph, Gemini Vision y Tavily para generar feedback nutricional y recomendaciones de alternativas. Todo orquestado y expuesto como API productiva en FastAPI con Pydantic.

- **📸 Zero-Shot Object Detection Service**  

  Servicio de visión por computadora para escanear comidas y detectar ingredientes de forma zero-shot. Implementado con PyTorch, TorchVision, Transformers y Grounding DINO. Incluye ciclo de feedback MLOps y desplegado como API en FastAPI.

- **💬 RAG Service**  

  Sistema RAG para responder consultas de nutrición y entrenamiento basado en PDFs especializados. Usa LlamaIndex, Groq (Llama 3.1), embeddings de Hugging Face y FastAPI para una API rápida y eficiente.

- **🔬 Scientific Research: T1D Stress & Exercise Detection**  

  Investigación en LEICI-UNLP: pipeline end-to-end de ML para detectar estrés y ejercicio en personas con Diabetes Tipo 1. Tecnologías: Random Forest, fusión multimodal de datos fisiológicos, procesamiento de señales y aumento de datos. Precisión: 0.78 en clasificación real-time.

- **😟 Stress Detection**  

  Detector de estrés basado en NLP, con redes neuronales desplegado en Hugging Face.

- **📱 SMS Text Classifier**  

  Clasificador de mensajes SMS usando NLP, LSTM, RNN y embeddings.

- **🐱 Cats and Dogs Image Classifier**  

  Clasificador binario de imágenes de gatos y perros con redes convolucionales (CNN) en TensorFlow.

- **📚 Book Recommendation Prediction**  

  Sistema de recomendaciones de libros basado en K-Nearest Neighbors y filtrado colaborativo.

- **❤️ Heart Disease Prediction**  

  Modelo predictivo de enfermedades cardíacas con Logistic Regression, XGBoost, Random Forest y Scikit-learn (incluyendo hiperparámetros y ensembles).

- **🎵 Song Popularity Prediction**  

  Predicción de popularidad de canciones: análisis exploratorio (EDA), limpieza de datos y regresión lineal con Python y Pandas.
